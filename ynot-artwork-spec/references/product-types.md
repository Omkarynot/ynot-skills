# Product-type reference (learned from 155 Y-Not sheets, Nov 2026)

Classify by the **actual product**, not by the folder, CSV category or filename. About 1 in 4 training
files were filed under the wrong category (backpacks under Drinkware, a tumbler under Bags, boxes
under Stickers, and so on).

Legend for each field: **A** = always on the sheet, **U** = usually, **S** = sometimes.
After sorting the user's info (step 3), any A or U field still empty is asked in step 5. Ask about S fields only when they fit the product.

Every sheet uses the same skeleton:
Title → `Specs` → Mockup (red dims + product-colour chip) → **Logo Placement** (flat vector product + logos +
dotted imprint areas, every category) → `<Location> Logo Artwork 1:1` with
`(<Method>)` → bottom row `Specs | Made in China label/sticker 1:1` (or `Specs | Features`).

## Apparel (tee, polo, hoodie, fleece, jacket, jersey, tracksuit)

**Checklist**
- **A:**
  - blank brand + style name (e.g. "Sport-Tek® Dri-Mesh® Pro Polo")
  - garment colour
  - sizes
  - size chart
  - fibre %
  - front + back views
  - print locations
  - method per location
  - logo W×H
  - PMS per colour
  - packaging
- **U:**
  - fabric weight (oz/GSM)
  - Features list
  - numeric offset (e.g. "3.5 inches below the Neck", "1.5" from the Cuff")
  - thread PMS / thread-match note (embroidery)
- **S:**
  - fabric type (pique, 3-end fleece)
  - location numbering "Location 1/2/3"
  - stitch count
  - colour count
  - made-in label
  - care instructions
  - tear-away label note
  - measurement guide
  - variants (by colourway, by size range, by team)

**Sections**
1. Mockup: Front | Back, plus Side when a sleeve is printed.
2. Logo Artwork 1:1 panels, 2 per row.
3. Made-in label, if one applies.
4. Size Chart.
5. Specs | Features.

Tracksuit: sub-headers Jackets | Pants, then a 2×2 artwork grid.

**Size chart**
- Finished flat measurements, or body ranges ("34-36").
- Measurement guide (optional): a flat sketch with colour-coded lines, e.g. "Body Length at Back: Measure from the high point of the shoulder (HPS)…".

**Placement wording**
- "*Align the logo horizontally to the center. For vertical positioning, place the logo 3.5 inches below the Neck, in accordance with the mockup provided above."
- "Logo placed Horizontally centered on the nape of the neck as shown in the mockup."
- "Note: Representation of the full chest logo may vary depending on the garment size."

**Embroidery**
- Header: "(Embroidery, 5500 stitches)" or "(Embroidery 1C) Location 1".
- Chip: "PMS Thread 2168 C".
- Note: "*Note: The Embroidery threads colors will be the nearest match to the color codes above."
- Note: "Note: There should be no stitches inside the circular background of the logo."

**Garment colour**
- Retail blanks use a vendor colour name, e.g. "Neptune Blue".
- Write it as `Color: Neptune Blue (vendor colour)`. Never write `PMS: Neptune Blue`.

**White ink**
- Show white or light logos on a block of the garment colour in the 1:1 panel.

## Headwear (cap, bucket hat, straw/cowboy hat)

**Checklist**
- **A:**
  - height, width, crown depth, brim width
  - offset from the brim edge ("positioned 1.5" above the edge")
- **U:**
  - circumference ("22.83" (58 cm) Adult")
  - panels / closure / visor / structure
  - brim stitch rows, eyelets, sweatband
  - inside view + label location
  - made-in label inside the cap
  - pack qty ("50 pcs/polybag, then into inner boxes, 200 pcs/carton")
- **S:**
  - ribbon, chin cord, cord lock
  - patch type + how it's attached ("Patch fitting method to hat: Stitching")

**Sections**
1. Mockups: Front, Back, Top or Right Side, Inside/Bottom with photo insets.
2. Logo / Patch Artwork, with the stitch count in the header.
3. Patch mockup, showing "Groove" and "White Stitches".
4. Ribbon strip at 1:1.
5. Made-in label 1:1 + Label Location photo.
6. Spec Details | Structure / Features.
7. Packaging reference photos.

**Dimensions**
- Curved dim for the crown, red ellipse for the circumference, diagonal dims for the brim.

**Cap label**
- 1" wide, segments 0.39 / 0.94 / 0.94 / 0.39".

## Bags (tote, backpack, duffel, cooler, lunch bag, pouch, case)

**Checklist**
- **A:**
  - H×W×D (red on the mockup and repeated in the specs)
  - material per component
  - imprint location + offset from the edges
  - method / size / PMS
  - packaging
- **U:**
  - handle drop / strap width
  - denier or GSM ("600D Canvas")
  - colour per component, each with its own chip
  - construction callouts (grommets, "Box X stitches", snaps)
  - made-in / wash-care label + location ("stitched inside the bag, 2 inches above from the base")
  - detail / reference images
- **S:**
  - volume ("1800 in³ (29 liters)", "24 can capacity")
  - weight
  - lining (+ lining print 1:1)
  - pockets with sizes
  - closure
  - child parts with "Qty for each bag"
  - convertible views
  - Features
  - poly-bag warning print
  - belly band / silica gel / gusset pad

**Sections**
- Simple tote: Mockup → Logo Artwork → Specs | Made-in Label.
- Constructed tote:
  1. Front | Back.
  2. Detail grid: Inside, Zipper Puller, Puller Charm, Pocket, Pouch, Gusset Bottom.
  3. Pattern / lining artwork 1:1.
  4. PU patch | Label.
  5. Belly band dieline.
  6. Reference images.
  7. Specs | Warning print.
- Backpack: Front | Side | Back → "3-Way Convertible" views → Detail Images for Reference → Features + Specs | Label.

**Strap repeat**
- Give the pitch and add "(The logo pattern will continue across the entire strap)".

**Material contrast**
- "Note: Due to differences in the materials used for the strap and the bag fabric, there may be a visible variation…"

## Drinkware (tumbler, mug, bottle, glass, cups)

**Checklist**
- **A:**
  - capacity in oz, with ml in brackets ("16 Oz (473 ml)")
  - overall H × W / Dia
  - body material
  - product colour + chip
  - imprint method
  - imprint size
  - packaging
- **U:**
  - rim + base diameter (cups, mugs, glasses)
  - insulation hours (steel)
  - imprint location
  - logo offset datum (base / steel ring / rim)
  - logo PMS
  - legibility note
  - Features
- **S:**
  - opening / mouth diameter
  - width including the handle
  - material per part (lid / straw / nozzle / seal)
  - lid closure type
  - Straw & Lid panel
  - colourways
  - BPA / FDA / lead-free claims (only with confirmation)
  - dishwasher / hand-wash
  - coating
  - weight
  - max imprint area
  - "Pre Printed Brand logo" callout on retail blanks
  - inner / carton qty
  - retail box + leaflet

**Sections**
- Tumbler: Mockup (front logo; back with brand-logo callout; lid views) → **Straw & Lid** → Logo 1:1 → Specs | Key Features.
- Mug: Mockup with a red base→logo dim → Logo → Specs. Use 2 colour chips when the interior colour differs.
- Bottle: Mockup + open-lid view with "Opening Diameter" → logo rotated for vertical print → Specs | Features.
- Disposable cup: Side A / Side B → Logo per side → Specs → Packaging reference images.

**Placement wording**
- "*Please align the logo horizontally to the center. For vertical positioning, place the logo 2.17 inches below the steel ring, in accordance with the mockup provided above."
- "*Logo placed on one side of the mug (refer the mockup), 2 inches from the base of the mug."
- Numbered note: "1. … vertically front of the bottle … 2. The Logo should be printed 2.64" (6.71 cm) above the base … 3. Available Imprint Area = 4" h x 1.25" w"

**Laser engraving**
- No PMS chip. Show the logo in grey/black, or white on black.
- Never show a laser logo in colour.

**Screen print**
- Header carries the count: "(Silk Screen - 1 Color, 1 Location)".

## Home & textiles (towel, blanket, pillow, cushion, coaster, frame)

**Checklist**
- **A:**
  - finished size
  - fibre %
  - imprint method + sides
  - packaging
- **U:**
  - GSM per part
  - base colour PMS
  - print / bleed / stitch template
  - logo position
  - wash care text
  - label artwork + location + material
  - made-in
- **S:**
  - folded size
  - thickness
  - weight
  - colour variants
  - closure
  - trims (zipper #, puller, strap, buckle, carabiner, hang tag, loop, drawstring)
  - construction / filling
  - thread colour
  - set count + holder
  - polybag warning
  - carton qty
  - Features
- **Frames (all A):**
  - photo size
  - insert
  - glass
  - stand
  - finish
  - how-to

**Sublimation**
- The print art is larger than the finished size (e.g. 16.10×13.27 printed for a 14×11 finished piece).
- Draw a green finished-shape line and a dashed "Stitch Line (Do not Print)" inset.
- Note: "Note: Please ensure the pattern is not enlarged, stretched, or distorted. Use the original files while maintaining the correct proportions."

**Coasters**
- Green "Coaster Die-Cut Print Area: 4" × 4" (Do not Print)".
- Red "Artwork Bleed Area: 4.27" × 4.27" (Do not Print)".
- Ceramic heat transfer: "2.5 mm white border around the design".

**Embroidery on throws**
- "CENTER OF ART 9" UP FROM CORNER (DIAGONAL ORIENTATION)".

**Sets**
- Show a "Set of 6" stacked view.
- Add a holder panel (an iso wire drawing + its own Specs).

## Notebooks / journals / planners / notepads

**Checklist**
- **A:**
  - size W × H
  - cover material + colour
  - page count
  - ruling (Lined / Ruled / Blank)
  - imprint method
  - packaging
- **U:**
  - paper GSM
  - logo offset from the bottom and left
  - made-in sticker
- **S:**
  - format name (A5)
  - binding (spiral, ring, hardcover)
  - closure (elastic / magnetic)
  - pen loop
  - bookmark ribbon
  - perforated pages
  - charms
  - weight

**Page count**
- Always state sheets AND pages: "80 sheets (160 pages)". The team mixes these up.

**Logo offset**
- Draw it on the mockup as two red dims (from the bottom and from the left), and repeat it in text:
  "Note: Logo printed on the front side of the journal, 3.44" from the bottom and 1.49" from the left side."

**Kits (notebook + pen)**
- Mockup row with sub-labels → logo per item → Planner Specs | Pen Specs → Made-in sticker.

## Pins / coins / medals

**Checklist**
- **A:**
  - size
  - thickness (side view)
  - base metal
  - plating
  - enamel type
  - PMS per fill + a Metal chip
  - back finish (frosted / gritty)
  - closure
  - bag type
- **U:**
  - fill colour count
  - clutch size (0.39" / 0.44")
  - post length (0.23") + position on the back
  - TM note
- **S:**
  - 2D / 3D
  - polishing
  - raised / debossed areas
  - min line width (0.52 mm)
  - magnet size
  - CMYK beside PMS
  - backing card
  - carton qty
  - made-in

**Template A**
1. Front | Side | Back, with a Butterfly Clip panel under Side.
2. Artwork 1:1 "(Soft Enamel Method)", with a cyan plating bracket diagram ("Gold Plating" ↔ "Soft Enamel Filled") and chips on leaders.
3. NOTE TM line.
4. Pin Specs.
5. Optional backing card (Front | Back) + Backing Card Specs.

**Template B**
1. Mockup.
2. Pin Artwork (method).
3. Specs | made-in sticker.

**Hard enamel**
- Callouts: Raised / Debossed / Hard enamel fill.
- Chip: "Silver raised metal finish".

**Plating**
- Goes in the Finish line: "Zinc alloy + Gold plating (Thickness 0.20cm)".

**Backing card**
- Size 3"×5" or 2.95"×3.93".
- Stock and print: "300g paper board", "Print: 4C (One side Print)", "Finishing: Glossy".
- Draw a dashed die line and a "Pin insertion hole".

**Coins**
- Header "(Die Molding)".
- Finish: "Polished Shiny Gold finish".
- Note: "Note: Ensure the back print orientation matches the front design."

## Trophies / acrylic / novelty

**Views**
- Six views: Front / Back / Right / Left / Top / Bottom.
- Green compass arrows (#00A650) on the top view.

**Print artwork**
- Front / Top / Back Print Artwork boxes, linked by arrows to the view they belong to.
- Mark "Do not Print" zones.

## Stickers / labels

**Checklist**
- **A:**
  - size
  - die shape
  - material
  - print method
  - PMS (+ CMYK)
- **U:**
  - finish (gloss / matte)
  - adhesive ("3M Vinyl", "Acrylic adhesive", "Removable adhesive")
  - base colour
  - packaging ("Shrink-wrapped in packs of 100.")
  - placement ("Location: To be pasted on the inner white box.")
- **S:**
  - thickness / lamination ("3.0mil lamination")

**Food label**
- Net Wt (oz + g), Ingredients, Contains, May Contain, Allergen Statement, Manufactured Onboard, Distributed by + address.
- All of it comes from the user. Never write any of it yourself.

**Product info sticker (inner box)**
- 2.5"×1": Product / Item No / Units per Pack / MADE IN CHINA BY Y-NOT.COM.
- Show it on a box photo with a red arrow to where it goes.

## Tags / cards / flags / paper decor

**Tags**
- Card size and stock + GSM ("Coated Art Card (400 GSM)").
- Sides printed, lamination.
- Hole "4 mm Dia".
- String: material, PMS, length, drawn straight ("Extended String 10" (25.4 cm)").
- Back drawn as the die outline only.

**Flags**
- Fabric GSM, stick length / material / top, "Flag & Stitch color".
- Colourway rows.

**Cruise decor**
- FR-treated cardstock.
- Magnets (Ø, qty), double-sided tape, assembly method.
- A "Purpose:" line.
- Construction Specifications template.
- "Recommended Manufacturing Instructions" block.

  - dims
  - colour per part
  - material
- **U:**
  - weight
  - capacity (mAh / GB)
  - battery type + qty
  - input / output V/A
  - wattage
  - ports + callouts
  - cable type + length
  - Features
  - imprint method + location
  - logo offset
  - manual
  - box includes
  - retail box
- **S:**
  - battery included?
  - adapter
  - Bluetooth version / range / device name
  - play / standby / charge time
  - compatibility
  - button legend
  - max imprint area
  - accessories
  - master carton
  - silica gel

**Sections**
1. Mockups with port callouts.
2. Detailed Images / Folding Options.
3. Logo Placement | Logo Artwork 1:1.
4. Retail Packaging Box (front/back + an opened box with labelled contents).
5. Box Includes.

## Packaging (own section, or its own page / file)

**Packing lines (text only)**
- "Bulk Packaging"
- "Each piece individually packed in a poly bag"
- "1 pc/OPP, 12 pcs/carton"
- "50 pcs per bundle, 20 bundles per carton, Total: 1000 pieces per carton"
- Write out the math for kits and case splits:
  "50 Blue + 50 Red + 50 Sticker sheets = 1 Case; 530 cases = 26,500 sets".

**Layered packing**
- "Each piece is separated by EPE foam. The full set is placed in a holder, then packed into a polybag and placed inside a gift box. 24 sets per carton."
- Numbered steps, with photos when available.

**Polybag warning (sticker 2.75"×1.18" or 2.5"×1.5")**
"WARNING THIS BAG IS NOT A TOY To avoid danger of suffocation, keep this plastic bag away from children and pets. Do not use this bag in cribs, beds, carriages or playpens"

**Belly band**
- Flat 16" + 0.5" glue × 2.75", with 2 fold lines.
- "Material: 200 g paper with coated", "Digital Print (Glossy)".

**Hang tag**
- 2.6"×2.6" or 2.5"×4".
- Barcode / price / SIN.
- Tag wire or elastic cord.
- 250–350 gsm, matte.

### Box dielines: how to draw them when none is supplied
General rules:
- Draw the flat at full bleed.
- Panel widths go along the **bottom** in one row of tick dims. The body height goes once on the **right**.
- Put the legend top-right and the chips under the flat.
- Show where the art lands on the Front/Back mockups above the flat, not by labelling panels on the flat.
- Rotate the art on panels that fold over (lid / back) so it reads correctly once folded.
- Back-panel info block: Product Name, Dimensions, Material, Colour, Weight, Input, Battery, Package Includes, CAUTION, MADE IN CHINA BY Y-NOT.COM, plus icons. Add CE/FCC only when the user confirms them.

**Reverse / straight tuck end** (most common)
- Glue flap ~0.5", tapered.
- Then 4 panels in the order Back | Side | Front | Side.
- The tuck lid sits on one long panel: width = that panel, plus a rounded tongue and a slit-lock nick.
- The adjacent panels carry dust flaps with a shoulder notch.
- Bottom: mirrored on the opposite panel (reverse tuck), or a lock-tab bottom.

**One-piece cross (tray + lid)**
- 3 columns.
- The centre column stacks bottom → front → top → back + tuck.
- The side columns are the end panels + dust flaps.
- Label any caliper allowance (e.g. 5.92 flat vs 5.90 box).

**Rigid magnetic / collapsible**
- Draw only the cover wrap: one strip with panels front flap | lid | back | base | front (e.g. 3|6|3|6|3), chamfered corners, fold lines.
- Material line: "150g paper (PMS …) mounted on 1200g cardboard" or "Cardboard (2mm thickness)".
- Call out the magnets on the open-view mockups ("Magnet-1", "Magnet-2", "Magnetic Closure").
- Add DIY assembly steps when the box ships flat.

**Drawer + sleeve**
- Sleeve flat: Back | Side | Front.
- Drawer: top + side views, plus "Ribbon Loop for Pull out Box".

**Tube label**
- W = π·D + ~1" overlap.
- H = tube height minus the metal end rims.
- One 1:1 panel per variant.

**RSC shipping carton**
- Panels L | W | L | W + a 1.25" glue flap.
- Top and bottom flaps = W/2.
- Material: "3-ply corrugated AB flute".

**Inserts**
- EVA foam / paperboard die-cuts: flat + 3D.
- Each cutout named and dimensioned ("Cutout to store <item>").

**Board specs seen**
- "350gsm white cardboard + matte lamination + E-flute corrugated (140gsm)"
- "3-ply corrugated AB flute, 600 gsm (Approx)"
- "Flat Packed"

**Seals and fillers**
- "Clear Sticker seal" / "Acrylic sticker seal".
- Crinkled paper + mailer box.
- Silica gel.

**Disclaimers**
- "Images are for bulk packaging reference only, not for individual packaging reference."
- "*Image shown is for bulk carton packaging reference only."

## Wording bank (use these exact phrasings)

**Legibility**
- "Note: The TM mark may not be legible in the final print."
- "NOTE: The Registered mark may or may not be legible on the print."
- "Note: Fine details may not be legible in the final print."
- "NOTE: Minor details such as the "R" mark may not be feasible in the actual print."
